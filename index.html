01 / About

What I do

Full-stack developer, plugin author, and the person keeping the server console quiet at 3am.

I started writing Skript to fix small annoyances on servers I played on — a vanish command that leaked join messages, a punishment flow that took too many steps. Two years later that habit turned into a full staff suite running GUIs, risk scoring, and live event systems.

Along the way I picked up Java and Kotlin to go deeper than Skript's ceiling, and rounded that out with general full-stack development and sysadmin work. I like tools that disappear into the background and just work — that's the standard I hold my own code to.

King of the Hill Engine

A capture-point event with a hand-written RGB gradient text engine. Interpolates hex values character-by-character — no external library, just math. Full event lifecycle from countdown to rewarded win.

/extravanish Utility
SkriptPermissions

Layered Vanish System

Tracks visibility as a relationship between every pair of online players — two vanished staff can still see each other while staying invisible to everyone else. Join and quit messages stay silent.

  • Per-pair hide/reveal logic across every online player
  • Silent join and quit messages while vanished
  • Live /exvlist of everyone currently vanished
/cmdspy Utility
SkriptLightweight

Command Spy

Staff opt in and every command on the server gets mirrored to them in real time. Clean on/off/toggle handling and self-filtering so cmdspy doesn't spy on itself.

  • Per-player opt-in with on / off / toggle
  • Real-time command mirroring to all subscribed staff
  • Self-filtering — the command never echoes itself
